# 🤖 AI Research Agent

An agentic AI app that searches the web and generates detailed research reports.

## Tech Stack
- Python + Flask (Backend)
- LLaMA 3 + Groq (AI Model)
- DuckDuckGo Search (Web Search)
- HTML/CSS/JS (Frontend)

## How to Use
1. Enter a research topic
2. Click Start Research
3. Get a detailed report instantly!
